# SoftGrowTech-RULE-BASED-CHATBOT
📌 Task 1 – Rule-Based Chatbot
🧠 Overview

In this task, I built a simple chatbot using Python to understand how basic AI systems work.
The idea was to create a program that can take user input, recognize certain words or patterns, and reply accordingly.

🤖 Project Description

This chatbot interacts with users through the console. It doesn’t use advanced AI, but instead follows a rule-based approach, where it checks for keywords in the user’s message and responds based on predefined conditions.

For example, if the user says “hello”, the chatbot greets back. If the user asks for the time or date, it provides the current information.

⚙️ How It Works

The chatbot follows a simple flow:

User Input → Keyword Matching → Response

It continuously takes input from the user and checks it using if-elif conditions to decide the correct response.

✨ Features
Responds to greetings like hello and hi
Answers simple questions like how are you
Tells the current time and date
Responds to “thank you” messages
Can tell a joke
Handles unknown inputs with a default reply
🛠 Tools Used
Python
Built-in datetime module
🎯 What I Learned
Basics of Artificial Intelligence
How rule-based systems work
Writing logical conditions in Python
Handling user input effectively
▶️ How to Run
python chatbot.py
📌 Conclusion

This project gave me a clear understanding of how simple chatbots function.
It also helped me build a strong foundation before moving on to more advanced AI concepts like machine learning and NLP.
