# SoftGrowTech-RULE-BASED-CHATBOT
🧠 Overview

Task 1 focuses on building a basic Artificial Intelligence system using a rule-based approach.
The chatbot processes user input, matches it with predefined patterns, and generates appropriate responses.

🤖 Project: Rule-Based Chatbot
📖 Description

This project is a simple chatbot developed using Python.
It interacts with users by recognizing keywords in the input and responding based on predefined rules.

⚙️ How It Works
User Input → Pattern Matching → Response Generation
The chatbot takes input from the user
It checks for keywords (like "hello", "time", "joke")
It returns a matching response
✨ Features
Greets the user
Answers basic questions
Displays current time and date
Tells jokes
Responds to help queries
Handles unknown inputs gracefully
🛠 Tools Used
Python
Built-in libraries (datetime)
🎯 Learning Outcomes
Understanding basic AI concepts
Rule-based decision making
Input processing and response generation
Logic building using conditions
▶️ How to Run
python chatbot.py


📌 Conclusion
This task helped in understanding how simple AI systems work using predefined rules.
It forms a foundation for advanced AI concepts like Machine Learning and Natural Language Processing.
